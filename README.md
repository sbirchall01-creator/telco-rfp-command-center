# Telco RFP Command Center

Hi, I want to build a new portal to handle RFPs from a telco to a software vendor looking to transform there create sell deliver process. I want the UI to be modern 2026 and be focused on all of the things required for a vendor to receive and respond to an RFP, think tier 1 telcos.
